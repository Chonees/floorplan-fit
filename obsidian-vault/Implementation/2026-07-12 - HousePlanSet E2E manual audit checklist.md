# HousePlanSet E2E manual audit checklist

Use this checklist to prove FloorPlan canonical adjustments propagate to ElectricalPlan.

## Required test matrix
1. Width-only compression.
2. Height-only compression.
3. Combined width + height compression.
4. Same house on a different setback/site plan.
5. At least one different FloorPlan/Electrical pair before claiming generic confidence.

## Pass criteria
- `verify-latest-plan-set-recipe-manifest.ps1 -RequireAutomatic` passes.
- Manifest status is `ReadyForExport`.
- Electrical status is `ProjectedAutomatically`.
- `CompressionRecipeSheets >= 1`.
- Observability audit files count is `8`.
- `OutlineSegmentCongruenceStatus = SegmentCongruent`.
- Structural missing/extra counts are both `0`.
- Electrical DXF exists, has entities, INSERTs, dimensions, ellipses, and wire/curve entities.

## Visual sanity
Open the exported FloorPlan DXF and ElectricalPlan DXF. For deeper CAD review, attach both into a blank AutoCAD drawing at origin `(0,0)` and scale `1`, hide electrical noise layers if needed, and compare the structural outline.

## Important scope
The pipeline propagates canonical adjustment recipe operations generated by the app. Random manual CAD edits outside the recipe are not automatically known unless represented as audited canonical operations.
